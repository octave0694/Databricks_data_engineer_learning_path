
Most importants topics to master Databricks.  

#### Overview

- Storage layer built on top of parquet.
- Open Source


#### Features

- Table layout : data files, log directory
- ACID Transactions: Atomicity, Consistency, Isolation, Durability
- Schema Enforcement and Evolution
- Time Travel
- Cloning (Deep & Shallow)
- Optimized Metadata Management
- Upserts, Deletes, MERGE INTO, and Complex Operations
- Compatibility with Various Storage Systems

#### Advanced Features
- Data skipping : Z-Ordering, Vacuum, Liquid Clustering, Partitioning, Column statistics
- Deletion Vector
- Change Data Feed
- Table Constraints
- Table Properties
- Table Details : DESCRIBE
- Checkpoints
